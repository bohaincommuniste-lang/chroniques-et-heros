# Chroniques & Héros

Application web **100 % statique** de gestion de fiches de personnages de Donjons & Dragons 5e.
Aucune donnée ne quitte le navigateur : persistance via **IndexedDB** (repli `localStorage`),
portabilité via **export / import JSON**.

## Prérequis

- [Node.js](https://nodejs.org/) ≥ 18 (uniquement pour compiler)
- Un navigateur moderne (Chrome, Firefox, Safari, Edge)
